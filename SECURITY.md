# Security Policy

## Do not disclose vulnerabilities in public Issues

This repository is public. Do not create a public Issue, Discussion, or pull request containing exploitable vulnerability details, credentials, private keys, authentication tokens, session cookies, or sensitive infrastructure information.

## Private reporting

Use GitHub's private vulnerability reporting feature for this repository if enabled:

1. Open the repository on GitHub.
2. Select **Security**.
3. Select **Report a vulnerability**.

If private vulnerability reporting is unavailable, contact the maintainer through the private contact method listed on the maintainer's GitHub profile. Do not publish exploit details while waiting for a private channel.

## Include in a private report

- A concise impact description.
- Affected app version or component.
- Reproduction steps that do not expose real credentials or third-party systems.
- Suggested mitigation, if known.

Do not test systems you do not own or have permission to assess.
