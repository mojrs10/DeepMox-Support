# Contributing to DeepMox Support

Thank you for helping improve DeepMox.

## Issues
- Search existing Issues before creating a new one.
- Use the matching Issue Form.
- Provide reproducible steps and the app version when relevant.
- Keep one distinct problem or proposal per Issue.
- Be respectful, factual, and on topic.
- Never post secrets, private infrastructure data, or personal information.

## Pull requests
This repository is primarily for public support tracking and documentation. Application source changes belong in the separate private DeepMox source repository. Documentation improvements may be proposed here; explain the reason and link a related Issue.

## Triage
The maintainer applies priority and workflow labels after review. An open Issue is not automatically scheduled work.

## Security
Never disclose vulnerabilities in public Issues. Follow SECURITY.md.
