# Issue labels

Labels are created and maintained by the GitHub Actions workflow in .github/workflows/sync-labels.yml.

## Type
- bug — reproducible defect
- enhancement — feature request
- ui-ux — usability or visual feedback
- question — usage question

## Area
- proxmox — Proxmox integration
- virtual-machines — VM functionality
- containers — LXC functionality
- terminal — terminal or console
- storage — storage
- backup-restore — backup and restore
- performance — performance or resource usage
- connection — network or authentication

## Triage
needs-triage, duplicate, needs-info, accepted

## Workflow
planned, in-progress, testing, fixed, wontfix

## Priority
priority-critical, priority-high, priority-medium, priority-low

Priority and workflow labels are applied by maintainers after review.
