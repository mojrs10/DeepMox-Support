# Frequently asked questions

## Do I need a GitHub account?
Yes. GitHub requires users to sign in to create an Issue. DeepMox opens the relevant public GitHub Issue Form in the browser.

## Are reports public?
Yes. Issues, comments, titles, and attachments are publicly visible. Do not include secrets or private infrastructure information.

## Does a feature request mean it will be implemented?
No. Requests are reviewed and prioritized by the maintainer. A planned label is not a delivery guarantee.

## How do I follow my report?
After submission, GitHub provides the Issue page. Bookmark it, subscribe to notifications, and follow maintainer comments and status changes.

## Can I report a security vulnerability here?
No. Follow SECURITY.md for private reporting instructions.

## Where is the application source code?
The source is maintained in a separate private repository. This public repository contains support reports and documentation only.
