# DeepMox Support

Public support and issue-tracking repository for DeepMox. The application source code remains in a separate private repository.

## Open a report
- [Bug report](https://github.com/mojrs10/DeepMox-Support/issues/new?template=bug_report.yml)
- [Feature request](https://github.com/mojrs10/DeepMox-Support/issues/new?template=feature_request.yml)
- [UI/UX feedback](https://github.com/mojrs10/DeepMox-Support/issues/new?template=ui_feedback.yml)
- [Question](https://github.com/mojrs10/DeepMox-Support/issues/new?template=question.yml)
- [Browse all Issues](https://github.com/mojrs10/DeepMox-Support/issues)

All Issues, comments, and attachments are public. Never post passwords, Proxmox API tokens, cookies, session identifiers, private keys, recovery codes, customer data, or unredacted infrastructure details.

Security vulnerabilities must not be reported publicly. Follow SECURITY.md.

This repository contains public support reports and documentation only. It does not contain DeepMox application source code.
